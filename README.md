# 🛒 Amazon Retail Analytics Dashboard | SQL & Excel

## 📌 Project Overview

The Amazon Retail Analytics project focuses on analyzing retail sales data using SQL and Microsoft Excel. SQL is used to query, filter, and analyze data, while Excel is used to create interactive dashboards and visualizations to generate meaningful business insights.

## 🎯 Objectives

* Analyze sales and revenue performance.
* Identify top-selling products and categories.
* Track order trends and customer purchasing behavior.
* Evaluate product performance.
* Create an interactive Excel dashboard for business reporting.

## 🛠️ Tools & Technologies

* **SQL:** Data extraction, filtering, aggregation, and analysis.
* **Microsoft Excel:** Data cleaning, PivotTables, charts, slicers, and dashboard creation.

## 📊 Key Features

* Sales and revenue analysis
* Product performance analysis
* Category-wise sales comparison
* Order trend analysis
* KPI tracking
* Interactive Excel dashboard with charts and slicers

## 🔍 SQL Analysis

SQL queries are used to:

* Calculate total sales and revenue.
* Identify top-performing products.
* Analyze sales by category.
* Aggregate order data.
* Identify trends and patterns in retail transactions.

## 📈 Excel Dashboard

The Excel dashboard presents key metrics and insights using:

* KPI cards
* PivotTables and PivotCharts
* Bar charts and line charts
* Slicers and interactive filters
* Summary reports for business analysis
